## MODIFIED Requirements

### Requirement: Standalone Hub Banner and Accent Color
Organizers SHALL be able to customize their standalone hub accent color (using Hue and Chroma intent sliders) and select a named Font Pairing, and upload a custom banner image for visual branding.

#### Scenario: Save Accent Color, Font Pairing and Banner
- **WHEN** an organizer updates the hub accent color (Hue/Chroma), selects a Font Pairing, and uploads a header banner cover
- **THEN** the organization's hub registry branding preferences are successfully saved in their custom theme record
